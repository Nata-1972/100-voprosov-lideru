100 ВОПРОСОВ ЛИДЕРУ: ИГРА + БОТ ВЕДУЩЕГО

ПЕРВЫЙ ЗАПУСК

1. В Telegram откройте @BotFather.
2. Отправьте /newbot и создайте отдельного бота для ведущего.
3. Запустите файл «Запустить игру и бота.bat».
4. Вставьте полученный токен в открывшееся окно и нажмите Enter.
5. Игра автоматически откроется в браузере.
6. Откройте созданного бота в Telegram и отправьте ему /start.

После этого вопросы, сохранённые учениками на втором этапе игры,
будут сразу приходить ведущему в Telegram без имени ученика.

КОМАНДЫ БОТА

/start — подключить ведущего к уведомлениям
/questions — показать последние 10 вопросов
/status — проверить подключение
/stop — отключить уведомления

Одновременно к боту подключается только один Telegram-чат ведущего.

КАК ОТКРЫТЬ ИГРУ УЧЕНИКАМ

Адрес для устройств в одной локальной сети появится в окне сервера,
например: http://192.168.1.15:3000

Компьютер ведущего и устройства учеников должны находиться в одной сети.
Окно сервера должно оставаться открытым всю встречу. Если Windows спросит
о доступе через брандмауэр, разрешите доступ только для частной сети.

ДАННЫЕ

Имена, Telegram ID и контакты учеников не передаются. Сервер не ведёт
журнал IP-адресов. Последние 100 вопросов и Telegram chat ID ведущего
хранятся локально в папке data. Удалите эту папку после завершения срока
хранения, принятого проектной командой.

Не публикуйте токен бота и не отправляйте его другим людям.
